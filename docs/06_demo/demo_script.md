## 常见问题

### 演示中断怎么办
1. `Ctrl+C` 停止所有节点
2. 检查 `outputs/logs/` 中的错误日志
3. 重新启动

### 如何重复演示
所有演示均使用固定随机种子，可完全复现。参数见 `configs/demo.yaml`。
